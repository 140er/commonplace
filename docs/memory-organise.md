# Organise memory

Open **Memory**, then **Organise memory**. Three views:

- **Facts** lists what the graph holds, with start and end dates, wing, sensitivity and sources. Type a name, exactly as stored, to see facts about it. An ended fact stays listed as history.
- **Stored sources and diary** lists places (wings and rooms); diary entries are the room named "Diary entries". Each stored text starts as its first part and opens whole, exactly as saved.
- **Links** lists the links between two places, with a label and how often each was used, and the automatic links inside a wing for reading.

Changes, all behind a review:

| Change | What it does | What stays |
| --- | --- | --- |
| End this fact | Marks the fact as no longer true from a date | The fact, its start date and its sources, in its history |
| Replace with a new value | Ends the fact and starts the new value on the same date | The old fact and its sources, in its history |
| Add a link | Joins two existing rooms | Both rooms and every stored text |
| Remove this link | Removes the link record | Both rooms and every stored text |

A review shows exactly what will happen. **Cancel, change nothing** sends nothing. If the stored state changed since the review, the change is refused and nothing is changed; reload to see what is stored.

This page cannot delete, bulk delete or rewrite stored text. Your access decides what you see and change: if the page says your access does not include something, ask a workspace owner.
