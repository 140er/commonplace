### Machine setup on the Deck home page

Since the Deck rebuild `#/needs` opens the home page (Waiting on you). That page now draws the runner setup consent cards that the classic list always drew, because the server already counts them in the owner's queue: a count that includes an item nobody can see is a defect, not a layout choice. The consent card, its checkbox and the refuse step are one shared piece of code; only the surrounding page differs.
