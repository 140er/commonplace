### Compute map in the Deck look

- In the Deck look the Compute screen is the only map: it draws the shared topology canvas from `GET /api/topology`, and `#/compute-map` resolves to it. When the topology is empty or unavailable it draws the hub and the enrolled runner machines instead, in the states Ready, Waiting for attestation and Off, with nothing about liveness, sites or routes.

The Capy Compute view extends this same canvas with token-based card styling and a 300px inspector. Its phone layout follows recorded directed links and shows a selected device in place of the map until Back is chosen. Recorded capacities and current usage remain distinct; missing service, health counters, version or bot facts are never invented. Runner readiness remains an enrollment fact, not liveness. The existing workspace administration flow owns Add a machine. Recorded link methods drive colour and live ends drive motion; idle links stay still and system reduced motion disables every dash animation. The optional panel renderer and layout function leave the classic view's defaults intact.

The approved compact presentation uses 48px nodes and straight 1px dashed links with local curves only around intervening nodes. No end dots, loose bundle counts or legend appear in Compute. Desktop nodes have 28px icon tiles; phone names stay on one line. The canvas fits and centres with 48px padding, at a minimum 360px desktop height. Title and status come before the tabs; only Fit and Reset remain in the canvas, and route selection belongs to Management. The classic topology presentation retains its existing routing and marks.

Compact status marks use a disc for healthy, a triangle for degraded, a diamond for unreachable and a hollow ring for unknown, stale or missing observations; colour is secondary and accessible labels retain status words. Compute restores borrowed workspace tabs to their original parent on departure. Panel decoration checks the upstream header, footer and read-only copy before modifying anything, falling back to the original panel if that contract changes.

The design follow-up uses one glyph renderer in node cards, Health and the named non-up summary observations. Degraded is violet; failure uses the approved rose, while amber remains reserved for owner decisions. Compute link and node selection are exclusive; selecting a link opens its recorded method, endpoint state and observation time, with Not reported for missing time. Only this presentation opts into the link inspector. On phone, shared spans have parallel 16px lanes and midpoint captions, while the fitted graph occupies the visible canvas above the bottom navigation. Enrollment actions follow the graph and the top bar keeps one plus shortcut to the existing Admin enrollment flow.
