### Card priority: the owner decides, the Coworker ranks the rest

Every card has a priority (`urgent`, `high`, `normal`, `low`; default `normal`) and records who set it. A signed-in workspace owner's priority always wins. The board's Coworker ranks the todo and backlog cards no person ranked, with a one-line reason in the card history, on start and when new cards arrive, and never replaces a person's choice; it raises a disagreement only when it really matters (a person-ranked `low` card blocking an `urgent` or `high` one), as one question to the owner. The runner trigger sweep starts todo cards most urgent first, then oldest, within the project's agent limit and skipping cards blocked by an open card. Open work: one-click priority change on the board card, a priority filter and a visible badge for the default level are a separate interface change.
