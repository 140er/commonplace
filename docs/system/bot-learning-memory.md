### Bot learning memory (store and switches built)

- `docs/design/bot-learning-memory.md` describes how bots learn lasting preferences and facts from a person's own words: default off per workspace and bot, private per-person scope, shared scope only after the owner's switch and the person's tap, real deletion on forget, and a fail-closed secret guard before every write. Slice S1 is built: the tables in `bots.sqlite3`, the owner switches (workspace and project), the person's mode, pause and forget-all (with a floor and a keyed block hash so a forgotten sentence is not learned again), real deletion of a row and its search entry, the secret guard seam (`learning.guard`, interim body until the fail-closed scanner lands) and list, edit and pin routes. Removing a `remember` note now blanks its text. Nothing extracts, retrieves or shares yet: with every switch off, which is the default, nothing is written.
