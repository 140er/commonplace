### Reservation removal in the card drawer

- Reserved Todo cards have a named Remove assignment action in both looks. Its confirmation requires the existing handoff note as a reason, explains board eligibility and posts `to: anyone` with the version the person saw. The existing route remains the authority and writes the same handoff event. Active claims and unapproved proposals do not offer this action; server refusals appear as plain text inside the drawer, with a refresh on version conflict.
