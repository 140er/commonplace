### Connection trust levels in Admin

- Levels: `untrusted` adds notes to its own inbox and cannot change or delete existing memories; `standard` reads and writes the wings it was given and can change existing memories but cannot delete or use admin tools; `trusted` has full access within its grants. The plain-words lines live in `commonplace/trust_levels.py` and reach the page through `GET /api/admin/workspaces/<id>/connections` (`trust_levels`, per-connection `trust_summary` and `trust_change`).
- Change: `PATCH /api/connections/<id>` with `{"trust": "standard"|"untrusted"}`, signed-in workspace owner only (members and agent tokens get 403). `ControlDB.set_connection_trust` re-checks the owner, refuses OAuth clients, runner and project bot connections, revoked or expired connections and any connection already `trusted`, never grants `trusted`, and runs the same `Policy.build` checks as token creation. Each change appends a `connection.trust` audit row with `reason` `<before> -> <after>`.
