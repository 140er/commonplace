### Home and personal decisions

The opt-in Deck Home is a composer over an undimmed local stage. It uses existing
bot chat and coworker conversation APIs. Context and model choices reflect the
hub's live fields and capabilities; missing capabilities have no controls.
Run progress belongs only to the message or job submitted by this view.

Today presents the authorized personal queue with the existing approval and
decision semantics. Successful decisions remove one version from every queue
bucket and navigation badge. A short exit animation and an Activity entry give
feedback without adding a write endpoint or broadening a person's permissions.

Hero controls use quiet labels over native selects, preserving keyboard behavior.
Only live capabilities enable overrides; a published current model does not grant
an unsupported write option. Retries bind to the original turn intent rather than
the current context. A known terminal failure starts a new receipt; uncertain
transmission retains its receipt to avoid duplicating an accepted turn.

Presentation separates explicit bot facts from queue-generated explanations.
Activity reads as sentences, highlights neutral for four seconds, and keeps the
same chronology and authorized event source. Deck palette descriptors use the
existing shell dispatcher and workspace-scoped roster; the classic palette keeps
its descriptors. Phone dismissal remains in the field row without a footer.

Send alignment is measured from the arrow path to the button centre at both
viewport sizes. Disabled opacity changes the same violet fill. Approval keeps
its primary rest colour through hover so a stationary pointer cannot make the
next card look busy or dim after the preceding decision exits.
