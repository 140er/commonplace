### Add machine and Add site

- On the Compute screen "Add machine" and "Add site" are one button each, no form. With a runner machine that can take the work the button starts a normal card start (the machine's own facts for a machine not yet on the map; one route trace for a domain); without one it copies a ready, generic prompt (and, for a machine, the short command) to paste into an agent on the machine. The only input is a domain name for a site. What the agent finds is a proposal, and the map changes only after the owner approves it in the app. Both buttons are the signed-in owner's.
