### Persistent previews, review round 2 (the card)

- **The owner's stop-rule form no longer collapses or loses what was typed.** It lives in its own element beside the status line, outside the list that is redrawn on every load, every 3-second repaint while something is published and every card refresh. It is built once per kind of viewer; afterwards only its sentence follows the server, and a field follows it only while it still holds what the server last sent. A whole-panel redraw (the card refreshes in the background) carries the form over: open or closed, with the typed values and focus. While the form has focus or unsaved text the shell's background refresh leaves the panel alone, like the other forms in the panel (`panelForm`). A refused Save keeps the form open with the text and puts focus back on Save with the reason in the status line.
- **Focus counts only when the control really holds it.** A control inside a closed `<details>` accepts a focus call and keeps nothing, so the heading fallback now runs for it.
- **Words.** The line under the list says the address a person opens works for 30 minutes and can be passed on within it ("share the preview, not the address; if parts stop loading, reload it from the card") and that a preview is a static page with relative links. A preview's publisher reads as words ("Release coworker") when the workspace has no display name for it. "Revision 2" reads "version 2"; the section says "Change when previews stop" instead of "stop rule"; the empty text no longer talks about a work session. The Open link reads "Open in new tab" and its accessible name starts with those words.
- **Announcements.** Stop, Open again and Save say what is happening ("Stopping…", "Serving it again…", "Saving the rule…") before the request, and the offline view says so in the status line as well as in the list.
- **Phones and touch screens.** The small print of the section is 14 px (it was 12.5 px) under `(pointer: coarse), (max-width: 699px)`; controls stay at 44 px. The rule's hint is tied to both fields (`aria-describedby`).
- **Not done (follow-up, card #627):** Open again opening the preview in the same click (a tab opened after a request is blocked as a popup in some browsers, so the second click stays); the publisher's display name from the server instead of the connection name.
