### Capy Bot overview and Coworkers

The opt-in Deck view presents each Bot section as one divided list. Unread
counts use the brand colour, private flags alone add a lock, and counts derive
from the visible conversation list or the older project-backed Coworker.
The existing Bot and conversation routes retain their addresses.

Optional work, ownership, log and model projections are read from authorized
responses. A project checkpoint remains the work fallback. Missing ownership
and log data do not produce placeholder panels. Redacted log tails enter the
DOM as text. The view reuses existing sharing controls and follows the same
Steer task-control and Chat message routes, with exact request retries.
An advertised unified-composer capability is required before sending a mode.

The desktop list is 260 CSS pixels, log content is 176 pixels high, and the
Sharing drawer is 460 pixels wide. Phone panels stack with 16-pixel gutters;
the composer scrolls below the work instead of covering it. Classic views and
the existing conversation controller retain their layout and authority checks.
