### Bot sharing in settings

Deck Bot settings lets a bot's owner choose workspace people by name, preview talk and shared-conversation permissions, grant or change access, revoke it, and read access changes in plain words. Private conversations stay private; shared conversations have a separate selector and an audience preview before creation. Workspace owners can adopt a bot whose owner left or enable a disabled bot. A member sees their own permissions without editing controls. The server remains responsible for every permission check.

Learned-item sharing names the project audience, shows the original words and the server's confirmation preview, and requires a separate tap before sharing. Shared bots do not offer personal learned-item sharing. These additions appear only in Deck; classic keeps its original settings. No new server route is introduced.
