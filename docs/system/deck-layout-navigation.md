### Deck layout and navigation

This belongs under the web shell decisions. The account menu (desktop) and the More sheet (phone) are one list of rows, so a destination is added in one place; Projects is left out of both because the sidebar already has the Projects heading. The account row is not a place and is never drawn as selected. The shell redraws on every data arrival, so the open account menu is kept open only while the route is unchanged. All desktop pages take one 20px offset under the bar from `#content`; a page's first block adds none.
