- **M:** [Owner pin guide](../runner-issuer-pin.md): one accepted installer plan
  shows and pins the owner's issuer public key. Enrollment supplies no trust
  root. Missing or altered pins block scoped producer calls and local status
  acceptance; independent hub verification and setup-only authority remain.

  remain the separate S9 follow-up. Only disposable enrollment proofs are allowed;
