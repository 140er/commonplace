### Meeting provider spike

- `docs/design/meeting-provider-spike.md` compares official meeting interfaces for the first adapter of the meeting-join bots (card #463, slice 6). Findings: no provider is a clean pass; Microsoft Teams is the only one whose official interface gives a joining bot, an audio stream and in-meeting chat, but it needs a Windows Server media host, tenant administrator consent and a developer-preview platform; Zoom RTMS has the better audio and transcript stream but cannot send chat; Google Meet's media API was discontinued; Slack huddles have no API. The note lists the owner decisions (accounts, tenant consent, where the media host runs, a design change if Zoom is chosen) and the adapter PR's test plan. Docs only: no adapter, account or app registration was created.
