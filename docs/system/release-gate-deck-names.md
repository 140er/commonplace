### The release journey drives the Deck look the way a person does

- The nightly journey went red when the Deck look became the default: the card panel keeps the release form under Edit card until Approve is pressed, and the Memory search box is named Search saved memory and has no Search button.

- Decision: both changes are deliberate and already tested in the app, so the journey follows them (press Approve, then fill the required Reason; type the query and press Enter) instead of the app restoring the older names or showing the form in advance.

- A name that survives only in the classic look passes the shipped-text check, so a second test pins the journey's Deck names to the Deck sources.
