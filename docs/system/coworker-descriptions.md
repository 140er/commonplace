### Coworker descriptions and new defaults

A Coworker works under a Bot, owns its code and uses subagents. Tool descriptions, skill instructions, receipts and owner-facing reasons use that term. Existing tool names, routes, JSON fields, schema values and configuration keys remain unchanged. No extra tool aliases are introduced. New seats default to `Coworker:<project>`; saved seats and connected identities retain their current names. Reconciliation accepts both name prefixes. There is no migration.
