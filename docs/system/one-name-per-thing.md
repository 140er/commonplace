### One name per thing

This belongs under the web shell decisions. A bot is the AI helper. A connected app is an outside tool such as Claude Code or Codex. A machine is a host. Waiting on you is the queue. Chat, the Memory From filter, project settings, the command palette, the classic rail, the Settings and project Connected apps headings and Admin's Runs on column use those names. Only the runner process on a machine keeps the word agent. Routes, ids, APIs, scope ids and stored data keep their spellings; Admin shows "Bot: <project name>" instead of the stored seat id.
