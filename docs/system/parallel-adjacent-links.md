### Parallel links between adjacent devices

- The routed Compute canvas gives a pair of links between same-row neighbours two straight lanes, offset by eight map units on either side of the centreline. Both strokes and their status marks must clear every label plate and other device; otherwise the existing router applies. Single links and non-adjacent routing keep their previous output. The grid search still reserves the same cells so unrelated links keep their geometry.
- Each routed link has its own pointer and keyboard target with a pressed state and highlight. Selecting a link does not open a device detail panel. The classic canvas retains its existing rendering and interactions.
