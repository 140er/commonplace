- **Owns:** The memory organisation routes in `commonplace/memory_organise.py`, mounted under `/api/organise/`. Reads: `places`, `facts`, `sources`, `source` and `links`. Changes: `facts/invalidate`, `facts/supersede`, `links/add` and `links/remove`. Each runs the matching worker tool (`mempalace_kg_timeline`, `mempalace_get_taxonomy`, `mempalace_list_drawers`, `mempalace_get_drawer`, `mempalace_list_tunnels`, `mempalace_list_hallways`, `mempalace_kg_invalidate`, `mempalace_kg_supersede`, `mempalace_create_tunnel`, `mempalace_delete_tunnel`) as the caller, through the gateway's full policy path.
- **Promises:** Nothing is deleted and no stored text is rewritten. A fact is ended or replaced with its history and sources kept; a link is added or removed while both places and every stored text in them stay as they are; drawers and diary entries are only read, word for word. No route deletes a drawer, deletes by source, deletes in bulk or updates a drawer. A change is a two-step call to one path: without `confirm` it answers what would change (`lines`) and an `effect_id` and changes nothing; with `confirm` and that `effect_id` it applies exactly that. Dates default once, at the preview, and are echoed back. Adding a link between two places that are already linked is refused, because that would replace the existing label. Access is unchanged: a read-only connection gets 403 on both steps and learns nothing about the fact.
- **How it fails:** A fact that is not current, not visible to the caller or ambiguous across wings answers 404 or 409 with "Nothing was changed". A stale or wrong `effect_id` answers 409 and changes nothing. A link's use count is shown at review but is not part of the change a confirm has to match, so crossing a link between review and confirm does not refuse the confirm; a changed link does. A busy, paused or starting memory answers 503 with a wait hint, never an empty list. An answer from memory that is not understood answers 502 and says to reload. A change that memory did not confirm answers 502 and says to reload to see what is stored.
- **Tests:** `tests/test_memory_organise.py` runs every route against a real hub and palace: facts with history, preview without change, wrong-effect refusal, confirm that keeps history, supersede, a read-only connection denied on both steps, verbatim stored text, empty rooms, link add and remove, duplicate and missing places, and a check that no stored text changes and no route can delete it.
