- **Owns:** `account/tables.py` classifies the preview tables (`previews`, `preview_revisions`, `preview_rules`) as workspace data that goes with a deleted workspace, and `preview_events` as an append-only table a purge keeps like the audit log (ids, actor labels and reason codes only). An export carries the preview rows of an owned workspace but not the published files under `previews/`; the export README says so.
