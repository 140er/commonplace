- **Promises:** A writer-scan refusal during an online backup names the process it found: its command line (credential shapes redacted, cut short), the environment variable or argument that pointed into the data directory (never the environment itself) and the process state. A process matches only when the path it names is the data directory or inside it, compared by whole path components, so a sibling directory that merely shares the name prefix (`data` and `data2`) never blocks a backup; a real writer in the data directory always does.
