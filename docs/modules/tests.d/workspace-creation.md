- **Owns:** Focused API, Node harness and optional real-browser evidence for workspace creation safety.
- **Promises:** The auth matrix covers person sessions, missing and mismatched csrf, service accounts and all bearer credential shapes. Acceptance includes ownership caps, concurrent requests, durable user and instance limits, disk/backup/maintenance refusal, default provisioning, admin inventory, card creation, real memory search and isolation. The public route inventory and spaces contract deliberately distinguish account workspaces from Spaces.
- **How it fails:** Browser checks skip only when explicitly disabled or their optional dependency/executable is absent. Each test uses isolated data; no production workspace is read. The original develop base already contained the route, so baseline evidence records missing safeguards rather than a fictional missing endpoint.
- **Tests:** tests/test_workspace_creation.py, tests/test_workspace_creation_safety.py, tests/test_workspace_creation_ui.py, tests/workspace_creation.mjs, tests/test_workspace_creation_browser.py, tests/test_commonplace_public_surface.py and tests/test_spaces_contract.py are the direct contract checks; existing workspace-store, invites, signup, CLI and plan tests cover adjacent behavior.
