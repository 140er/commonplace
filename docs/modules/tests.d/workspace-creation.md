Acceptance includes ownership caps, concurrent requests, durable user and instance limits, disk/backup/maintenance refusal, default provisioning, admin inventory, card creation, real memory search and isolation.   Closed-instance cases distinguish the stored admin flag from workspace ownership, admit exactly allowlisted stored emails with the shared parser, refuse ordinary members with the plain 403 and pin admission-rule audit priority. The original develop base already contained the route, so baseline evidence records missing safeguards rather than a fictional missing endpoint.
