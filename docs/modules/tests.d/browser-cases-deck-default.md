- **Tests:**

  - The real-browser cases (`tests/test_*_browser.py`, plus `test_projects_connect_ui.py`, `test_remove_assignment.py`, the Chromium cases in `test_commonplace_oauth.py`, `test_commonplace_decide_*.py`, `test_compute_browser.py` and `test_coworker_browser.py`) skip where Playwright or Chromium is missing. To run them install the Playwright package that matches your cached Chromium build into the project environment, point `PLAYWRIGHT_BROWSERS_PATH` at the real browser cache (a sandboxed home hides it, and the cases then fail with "Executable doesn't exist") and run the files in groups of about eight, which stay under eight minutes.

  - Since the Deck look became the default, a case that is about the classic look opens `/app/?ui=classic` (the shell stores the choice under the `cmmn.ui` key, `classic` or `deck`; the Node harnesses seed it through `storage({ [deck.UI_KEY]: "classic" })`). Cases for the Deck assert its current tokens: surface `rgba(20, 19, 25, 0.94)`, well `rgb(27, 26, 33)`, ground `rgb(9, 9, 12)`, ink `rgb(237, 237, 242)` and strong line `rgba(255, 255, 255, 0.1)`. Outline checks read colour, style and width separately because Chromium orders the `outline` shorthand differently between builds.

  - One Deck gap is kept as a strict expected failure so it cannot be forgotten: the Needs me filter does not match the board segment style. The Compute bundle count badge gap is closed and its case is a plain assertion. An unexpected pass fails the run, which is the cue to turn the marker into a plain assertion.

  - Two further cases follow the current screens. The Compute status line case reads the no-runner line from `deck-compute-work.js` and asserts it comes before the map on desktop and phone, so a wording change in the source cannot leave a stale copy behind. The card drawer helper in `tests/test_remove_assignment.py` waits for the card's own read (the read-only preview carries `data-card-preview`) before it opens the edit controls, so the removal cases no longer race the preview. Cases that use a real gateway and an on-disk database can time out on a disk under heavy load; point pytest `--basetemp` at a memory-backed directory for those runs.
