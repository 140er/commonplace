- **Owns:** Regression coverage for the card's review comments, owner settings, Pipeline chip and the answers shared with Needs me.
- **Promises:** The node harness exercises loading, status words, refusals, paging, original text, focus and owner controls. Browser checks cover owners and members in Deck and Classic at desktop, 390, 320 and 768 touch sizes, readable phone text, touch targets, settings saves, and focus after an answer and a background redraw. A real local server verifies the settings link, reload, Back and Close in both looks at all four sizes. Server checks preserve workspace and role boundaries, associate an answer with its review question, and prevent a replay from changing later comment revisions.
- **How it fails:** Missing browser dependencies are skips rather than evidence; an import failure in the standalone project display helpers fails the existing node wrappers. A failed assertion or missing matrix state cannot count as a passing walkthrough.
- **Tests:** `tests/test_card_reviews_ui.py`, `tests/test_card_reviews_browser.py`, `tests/test_pr_review.py`, `tests/test_pr_review_loop.py` and all node-harness wrapper files when a shared shell module changes.
