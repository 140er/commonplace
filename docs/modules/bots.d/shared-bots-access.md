- **Owns:**

  - Effective access (slice S2): `access.effective` is the one function that decides what a turn reaches: for a shared bot the bot's `bot_access` list ∩ the talker's fresh person principal ∩ the owner's, for any other bot the person's own reach (the list is not read). `Turn.effective`, `Turn.readable`, `Turn.board` and `Turn.machines` go through it, `tools.gate` runs on every tool call and again at a confirm tap, `tools.offered` drops what the list does not name or whose `reach` it does not cover, and `context` builds the snapshot and the system line only from the effective reach. `Tool.reach` (`none`, `project:read`, `project:write`, `machine`, `wing:read`, `wing:write`) is required: `register` refuses a tool without it, a project reach without scope `project`, and a project tool with a reach that is not a project or a machine. `my_access` is a built-in read tool offered to shared bots only. Refusals are fixed sentences (`outside_bot_access`, `bot_read_only`, "can't find that") that never name a project. `routes.py` serves `GET`/`PUT /api/bots/<id>/access` and `GET .../access/log` (owner edits, members read; `PUT` is web session only, compare-and-set, one audit row `bot_access:set` per real change). `BotStore.viewable` reads a bot for its owner or a member with a live share. No share route exists yet: a bot is marked shared through `BotStore.share` (fixtures).
