- **Owns:** `delivery.py` builds and explicitly configures offline program packages; `machine_setup.py` verifies and publishes a private dependency-complete program prefix before continuing existing setup.
- **Promises:** Exact dependency versions and RECORD hashes, owner-command digest pins, purpose/platform checks and per-file inventories precede publication; normalized Python configuration and saved archive verification also precede reuse from either interpreter. Delivery never grants enrollment, readiness or execution authority.
- **How it fails:** Missing, changed or unsafe artifacts and prefixes refuse without replacing earlier files or changing services; runtime authority remains setup-only.
- **Tests:** `tests/test_runner_program_delivery.py`, `tests/test_runner_program_delivery_regression.py`, `tests/test_runner_bootstrap_resume.py` and `tests/test_machine_setup.py`.
