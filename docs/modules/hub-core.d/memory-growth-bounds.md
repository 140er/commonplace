- **Owns:** `commonplace/bounded_map.py` is the small least-recently-used map the mediator keeps its last tools list per workspace in. `Gateway.release_idle_memory` is called from the idle sweep and asks the handoff context to hand back idle stores' page cache. `WorkerSupervisor.worker_snapshot` is the read-only list of running workers (pid, uptime, RSS, anonymous and file memory) that the Admin deploy view reads. The launcher passes `COMMONPLACE_WORKER_RSS_RECYCLE_MB` from the gateway's environment to each worker as `MEMPALACE_WORKER_RSS_RECYCLE_MB`.
- **Promises:** What the gateway keeps per workspace is bounded: the tools list held for a backup pause is kept for the 128 most recently used workspaces, the warm-up table holds only the last interval's workspaces, a restart circuit with no failures is dropped with its idle worker, and the storage meter forgets totals past their minute. None of this changes what a call answers. The recycle ceiling is off unless the gateway's variable is set; the operator's own `MEMPALACE_WORKER_RSS_RECYCLE_MB` never reaches a worker.
- **How it fails:** A worker that cannot be read still lists in the snapshot with unknown memory, and a failing snapshot lists nothing; it never raises into the status view. A tools list evicted from the cache is only missed during a backup pause, which then shows the usual paused answer.
- **Tests:** `tests/test_memory_growth_bounds.py` drives a thousand workspaces through each table and asserts what is held at the end, and covers the launcher passing the ceiling only from the gateway's switch.
