- **Owns:** The per-request wait budget of the worker supervisor (`workers.memory_wait`, `WorkerSupervisor.call`, `_get`) and what the gateway does with it: `Mediator.handle` and `call_memory_tool` give each request `COMMONPLACE_MEMORY_WAIT_S` (default 5 s) for backup-pause and worker-start waits in all its worker calls; `WorkersStarting` / `WorkerStarting` is the new "still starting" refusal and `extensions.RetryableToolError` carries `reason` (`paused`, `starting`, `busy`) and `retry_after_s` to the route. Index writes (`internal/write_mirror_units`) never wait for a pause.
- **Promises:** A person's request waits for a pause or a start for the budget at most, in total; a pause met once is not waited for again in the same request; a worker start that outlives the budget finishes in its own thread and releases the callers that wait on it. Calls without a budget keep the old waits (`pause_wait_s` for a pause, 30 s for a replacement). Each refusal and each wait of a second or more logs one line with the wait and its bound (no user content).
- **How it fails:** A budget of 0 refuses at once while paused or starting; a start that fails reaches the request that began it as before.
