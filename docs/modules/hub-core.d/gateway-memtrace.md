- **Owns:** `commonplace/memtrace.py` owns the gateway's opt-in allocation sampler and process counters; `Gateway.serve` starts and closes the sampler with the HTTP service.
- **Promises:** Only `COMMONPLACE_MEMTRACE=1` enables tracing (five frames). A background thread keeps the preceding snapshot and logs at most ten positive allocation differences every 600 seconds, using code file and line, byte count and allocation count. No request content or absolute source paths are logged. An existing tracer is reused and never stopped by this sampler.
- **How it fails:** Sampling failures log a fixed message and retry on the next interval. Missing process counters remain unknown; tracing remains off for every other switch value. Closing wakes the sampler and releases its snapshot and any tracer it started.
- **Tests:** `tests/test_gateway_memtrace.py` covers the default, explicit switch, privacy, ten-site limit, snapshot rotation, sample failure, tracer ownership and HTTP shutdown; `tests/test_gateway_memory_growth.py` checks retained allocations and resources under varied polling.
