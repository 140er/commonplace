- **Owns:** `deck-coworkers.js`, `deck-coworkers.css` and `deck-coworker-sharing.js` render the Deck Bot overview as one divided list per section and the nested Coworker view as a 260px list beside recorded work. `bots.js` keeps the classic roster and exposes its existing sharing controller to this view.
- **Promises:** Optional `working_on`, `owns`, `live_log`, model and composer capabilities are detected per response. Existing checkpoints supply older work steps; missing ownership and log projections stay hidden. Log tails use `textContent`, preserve server redactions and scroll to the end. Models appear only in the detail heading. The phone composer follows the panels in normal document flow. Sharing retains its existing authority checks and permission previews inside an opaque 460px drawer with inline permission selects and pinned Save / Stop sharing actions. Removing all shares requires a named confirmation and uses the existing per-person revocation route. Scrolling tabs fade only at cut edges, align with the drawer title and sit 12px below its explanation. Permission selects use the flat Deck fill and 12px radius. Phone Bots retains its top-bar label. Access history uses “You” for the authenticated viewer, matching by identity rather than display name.
- **How it fails:** Missing conversations cannot grant task controls. Steer targets the newest authorized job's follow-up route; Chat retains explicit single-bot versus group addressing. Only an advertised unified composer receives a mode field. Unconfirmed writes retain their exact request ID and text for an explicit retry. Refusals clear private work and controls; departure aborts reads and fences late responses. Existing conversation routes and the classic layout stay unchanged.
- **Tests:** `test_deck_coworkers.py` wraps browser-free feature-detection, route selection, exact retry, redaction and lifecycle checks. `test_deck_coworkers_browser.py` optionally checks both viewport sizes, panel hiding, mode switching, drawer reuse, log scrolling, dimensions and overflow.
