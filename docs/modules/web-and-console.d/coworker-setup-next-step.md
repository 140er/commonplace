- **Owns:** Shared bot creation fields in `bot-create.js` and outcome recovery copy in `coworker-setup.js`, used by the Bots and Coworker controllers.
- **Promises:** Both create screens say Create bot, preserve entered values on failure, and validate trimmed human names before sending. Empty conversation prerequisites open that same editor; empty project rosters offer Add a bot. Missing models link Project settings, missing machines link enrollment, and failed replies explain a recovery action.
- **How it fails:** Members without bot-management permission are told to ask the workspace owner. Unknown failures do not invent a missing model or machine. Settings links cancel navigation before loading the existing project panel.
- **Tests:** `test_coworker_setup_next_step.py`, `test_coworker_setup_browser.py`, the Coworker UI and Bots harnesses, and the durable conversation browser journey.
