- **Owns:**

  - `deck-art.js` and `deck-art.css` own the decorative dithered art on Deck empty and loading states: Today all clear and its empty bots line, the Bots list and Home roster note for no bots and loading, an empty Board column, Memory after a search found nothing, the Loading card hint, the Memory page title row, one cue beside each Memory import step title (choose, check, preview, report), the rail's no-bots note, the older Today view's all-clear line, and a thin fading line in the Today section headers. `deck-art-data.js` is generated by `scripts/capy_art.py` from our own sprites in `design/capy-art/` (made by `make_sources.py` from the cmmn mark) with a 4x4 Bayer threshold, and is never edited by hand. Library items are design reference only (`docs/system/own-dither-art-only.md`).

- **Promises:**

  - Each piece is an `aria-hidden` element with a text-free inline drawing in the surrounding text colour, so it follows the Deck, light and dark looks. It never animates, scales down inside its box and adds no text; pieces that sit beside a title add no height, and the section line and Memory title piece are hidden below 700px so the phone stays uncrowded, so the existing words stay the accessible content and unchanged. Each piece is under 4 KB and the set is under 20 KB.
  - `showLoading` takes an optional art name; without it the markup is exactly as before.

- **How it fails:**

  - An unknown art name renders nothing, so a missing sprite leaves the plain text state. The generator reads only 8-bit grayscale PNGs and stops on any other input.

- **Tests:**

  - `deck_art.mjs` and `test_deck_art.py` cover each spot (hidden, text-free, words unchanged, no art once content exists), the size limits, and byte-for-byte regeneration of the committed art by the script.
