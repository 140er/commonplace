- **Owns:**

  - The node detail panel (`topology-detail.js`, `topology-detail.css`): when a device is selected on the Compute map it reads `GET /api/topology/node` and `GET /api/topology/route` and shows four read-only tabs. Physical: hardware, OS and resources with when each was last observed. Config: how to connect as rows and copyable text, and the answer `topology_route` gives an agent, unchanged. Agents: connections, runs and the coordinator's checkpoint, each linking to its card or log. Sites: the routes the device hosts or passes, each with a button that highlights it on the canvas through the canvas's own route picker. Every value shows its source and age, a stale value says so in words, a device with nothing to show has a plain empty state, and nothing in it is editable. It creates its element on the first selection, polls like the canvas while a device stays selected, and removes itself with the canvas's markup.
