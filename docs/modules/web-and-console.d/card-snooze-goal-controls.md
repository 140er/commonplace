- **Owns:** Card return and goal controls in `card-controls.js`, shared by the Deck panel and classic drawer; plain return-time lines on both boards. A snoozed card replaces its older waiting callout with one return line in the reader's timezone.
- **Promises:** Snooze, Wake now and Goal use the existing services and routes. Calendar shortcuts and picked times use the person's browser timezone. The owner can edit; other readers see the current goal and return time. Controls arrive only after the card read.
- **How it fails:** Refusals appear beside the controls without changing the card. A failed goal-list read leaves the current goal visible and editing disabled. Concurrent taps share one pending write; navigation fences late results.
- **Tests:** `tests/test_card_snooze_controls.py`, `tests/card_snooze_controls.mjs` and `tests/test_card_snooze_controls_browser.py` cover both looks, timezone shortcuts, literal goal text, owner controls, failures and responsive positions.
