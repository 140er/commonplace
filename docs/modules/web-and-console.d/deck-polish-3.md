- **Owns:** `projects.js` (`mountProjectReview`) and `deck.css` own the Deck Coworker config review spacing and result copy and the gap between the phone notification buttons; `deck-coworkers.js` (`capyRosterHTML`) owns the Bots list avatars, which now take the sidebar's `botInitials` from `deck-shell.js`.
- **Promises:** In the Deck look the Accept button sits 8 px below the Changes line, collapsed or open. After a decision the version row is the only result: the repeated "Rejected vN" or "Accepted vN" status line is gone, and classic keeps its line. A bot has the same initials in the sidebar and in the Bots list (for example "CO" and "CW" for two bots that share a first letter, never the lowercase first letter as typed). "Test" and "Turn off" in the phone notification settings keep a 12 px gap.
- **How it fails:** A failed refresh or failed decision still shows its own status text. The Bots list gets the same initials only for bots it is given; a bot missing from one of the two lists can still be labelled differently.
- **Tests:** `tests/test_deck_config_review_browser.py` and `tests/test_deck_polish3_browser.py` serve the shipped static files with fixture data and measure the pixel gap above Accept at 1280 and 390, the absent result line, the matching initials and the button gap, red on the previous build; `tests/project_config_review.mjs` pins the absent line in the Node controls.
