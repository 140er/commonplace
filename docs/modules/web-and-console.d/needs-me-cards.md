- **Owns:** `needs-me.js` is the one definition of "needs me" in the web shell: the owner queue's cards, the count derived from them, queue membership for a card, and the display helpers that shorten text and remove references without leaving a gap. Today, Home, the shell badges and the Deck Board read it; none keeps a count of its own.
- **Promises:** A Today or Home count is the number of distinct cards in the owner queue, never a stored `count` field. The Board's Needs you column holds exactly the cards that queue lists; where a project holds only part of the queue, the Board says so in words. A Today card shows a plain title, a one or two line preview and a visible main action (Approve, Answer, or Open) beside Hold and Reply. The full stored words sit behind a Show full text control, exact and unedited; only the display is shortened. Removing a reference such as a card number or a path from display text leaves no empty brackets, doubled commas or dangling connector words.
- **How it fails:** A member who cannot read the owner queue has no lists, so the plain number from the response is used and the Board keeps each card's own flag. A payload with neither shows nothing instead of a false zero.
