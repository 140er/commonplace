- **Owns:** `deck-tree.js` (placement of projects under bots, the current row, the key rules, the per-device folded set) and the tree part of `deck-shell.js` and `deck-shell.css`: the Deck rail draws one tree of bots with their projects nested and an Unassigned group, and the Bots screen carries the same tree on a phone (`bots.js` hosts it).
- **Promises:** Each bot row opens and folds (state kept per device, the row of the page being viewed opens on arrival), a bot without projects shows an empty note, projects the person cannot read never appear, and the tree uses `role="tree"` with one tab stop, arrow keys, Home, End, and M to move a project; focus stays on the same row across redraws (`app.js` keeps it when it redraws the rail). Rows keep the existing rail styles; only indent, chevron, empty note and move chooser are new.
- **How it fails:** A failed move shows one short line and leaves the tree as the server last reported it; a roster that has not loaded draws no Unassigned group; unreadable storage means nothing is folded.
- **Tests:** `tests/deck_bot_tree.mjs` (run by `tests/test_deck_bot_tree.py`) covers placement, semantics, current row, folding and keys; `tests/deck_shell.mjs` still covers the rail.
