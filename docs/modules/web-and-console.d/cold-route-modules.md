- **Owns:** Route controller imports, route styles, parallel module discovery and static asset revalidation.
- **Promises:** The shell loads independently of unopened route controllers; all existing styles retain their document order without duplicate route links; Deck prepaint precedes the entry module; identity retains its ten-second first attempt and three bounded retries.
- **How it fails:** Failed imports or styles leave a plain Retry state without signing out; a CSP-hashed inline guard survives failed module fetches and retries the document after 1/2/4 seconds, with manual Retry after exhaustion; the module watchdog stops at boot so identity keeps its own deadline; concurrent imports share a promise; stale route completions cannot replace a newer route; asset validators preserve cached bodies.
- **Tests:** tests/test_cold_modules.py, tests/test_workbench_tokens.py, tests/test_boot_recovery.py, tests/test_module_boot_guard.py, tests/cold_modules_browser.py and all Node harness wrappers.
