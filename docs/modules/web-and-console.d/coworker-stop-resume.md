- **Owns:** `orchstatus.js` owns the Coworker row of Project settings: Stop Coworker (the existing force-release, behind a confirm), Resume Coworker (owner-resume, behind a confirm), the list of failed card starts with their reason (`MISS_REASONS`) and the recent Coworker activity list (stops, resumes and claims, with who and when).
- **Promises:** Stop shows while a lease is live and Resume while nobody coordinates, only to the signed-in owner; the row redraws from a fresh read after each action without a reload. A failed card start names its reason in plain words, and a reason the page does not know is shown with its code instead of being dropped. No lease token is ever drawn. Void, reassign and retire are still not offered here.
- **How it fails:** A refused or failed Resume says why (a Coworker already running, a restore waiting, no accepted config, not the owner, project gone) and changes nothing; the button stays available.
