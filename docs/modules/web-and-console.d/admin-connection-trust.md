- **Owns:** The trust column of Admin connections (`commonplace/web/static/admin.js`, `connections()` in `commonplace/web/admin.py`) and the bot start-permission form in `commonplace/web/static/projects.js`.
- **Promises:** Each connection shows its level with the one-line summary the server sends (`trust_summary`, from `commonplace/trust_levels.py`), a legend of all levels, and either the owner's change buttons (with an inline Confirm and Cancel step before the `PATCH /api/connections/<id>` write) or the reason it cannot change. The write is skipped unless the page was loaded by an owner and the server offered that level, and the list is read again afterwards. With no machine registered, the start-permission form is replaced by its blocker and a link to add a machine (`#/compute`, `#/compute/management` in the deck look); trust already granted can still be removed.
- **How it fails:** A refusal shows the server's owner-safe message; any other failure shows a fixed "Could not change the trust level" line and never the response body.
- **Tests:** The `trust` case of `tests/admin_runtime_ui.mjs`, `tests/test_trust_form_blocker.py`, and `tests/test_connection_trust_level.py` for the projection.
