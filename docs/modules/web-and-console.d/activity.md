- **Owns:**
  `activity.js`, `activity.css` and the nested Activity integrations in `routes.js` and `deck-workspace.js`: Compute > Activity with Recap, Time sinks, retained thread summaries and Live views.
- **Promises:**
  The four global destinations stay unchanged. Measured values or unavailable reasons retain the source window, collection time, local timezone and coverage. Thread identifiers are plain text in this slice; there is no detail button, detail request or phase-bucket view. Time sinks uses the global retained ranking independently of list filters and pages. Phone rows retain visible labels and semantic table headers. Keyboard pagination restores visible focus and announces the result range.
- **How it fails:**
  Missing collection, denied access, failed refresh, capped retention and stale snapshots remain distinct states. Cached aggregates display only for the selected source while its authoritative consent state remains active. Source replacement, acknowledged revocation or enumeration with disabled consent clears the snapshot, model filter, page and paging focus before dependent reads. A later failed read cannot restore revoked aggregates. A failed refresh of the same source with active consent retains its snapshot with a stale-data warning. Refresh reads stored aggregates and does not rescan the source. Hidden, paused or departed screens do not poll. A failed request does not become zero activity. Narrow screens retain the Activity heading and named controls.
- **Tests:**
  `tests/activity_ui.mjs`, `tests/activity_regressions.mjs`, `tests/deck_workspace_pages.mjs`, `tests/test_compute_activity_browser.py`, `tests/test_compute_activity_browser_regressions.py` and the existing workspace navigation wrappers cover this slice. Detail rendering and its snapshot-provenance regressions arrive with the detail view.
