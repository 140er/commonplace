- **Owns:** Delete this note in the shared Memory source panel and its narrow-screen confirmation.
- **Promises:** Deck and classic render the action only from an authorized server offer. The native dialog shows escaped first lines, Cancel and Delete. Success removes the result, closes the panel and says Note deleted.
- **How it fails:** A failed delete retains the note and confirmation with a plain error. Pending writes block duplicate submission; stopped controllers ignore late replies.
- **Tests:** tests/test_memory_note_delete.py, tests/test_memory_note.py and
  tests/test_memory_note_delete_browser.py exercise the note deletion boundary.
