- **Owns:** `deploy/commonplace/Dockerfile` defaults the gateway process to `MALLOC_ARENA_MAX=2` before Python starts; `deploy/commonplace/DEPLOY.md` explains the gateway allocation diagnostic and the added thread and descriptor counters.
- **Promises:** Operators can override the arena count through the container environment. The diagnostic remains off by default and needs an explicit operator environment change and a gateway restart. It writes allocation-site metadata to the gateway log and leaves user content out.
- **How it fails:** Tracing adds CPU and memory overhead and cannot explain native allocations; use an untraced run to validate the anonymous-memory slope. Missing counter data is unknown, never zero by assumption.
- **Tests:** `tests/test_gateway_memory_growth.py` starts the gateway with the image environment and asserts the actual glibc arena count remains at most two across concurrent transcript uploads (31 arenas on the original image setting). `tests/test_gateway_memtrace.py` verifies the switch and logging contract; `tests/test_admin_instance_api.py` verifies the authenticated deploy payload.
