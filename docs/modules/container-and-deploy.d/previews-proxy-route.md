- **Owns:** the private and public Caddy templates and `deploy/commonplace/DEPLOY.md` route `/p/*` to the gateway (the app host, not the agent host), so a published preview opens in production; `deploy/PUBLIC.md` lists it for the app host and adds a check that an unknown preview address answers a gateway sign-in page while signed out, or 404 while signed in. The proxy does not add `X-Frame-Options` on `/p/*` (the gateway sets it); every other path keeps `DENY`.
- **Promises:** the viewer and its files receive their framing policies from the gateway; other app and consent pages retain the proxy deny policy.
- **How it fails:** a missing preview route shows the static fallback, while a duplicate deny header prevents the viewer from loading its frame.
- **Tests:** `tests/test_commonplace_deploy.py` checks both proxy matchers and the framing exception; preview HTTP and browser cases check the gateway response.
