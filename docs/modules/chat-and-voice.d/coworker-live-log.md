- **Owns:** `commonplace/chat/coworkers/livelog.py` projects scoped job output; `steps.py` projects the working-on tree. The complete API contract and examples live in `docs/system/coworker-live-log.md`.
- **Promises:** Cookie-person, conversation and current project authority fence every read; markup, escapes and controls normalize before shared redaction, path masking and truncation. Tails retain at most 200 lines of 500 characters from 20 jobs; reads are rate limited and capped at eight concurrent readers, without retained subscribers or new output storage.
- **How it fails:** Invalid or foreign-scope cursors are rejected, stale cursors reset the tail, revoked or rebound sources disclose no output or run steps, oversized sources are omitted, and busy or rate-limited reads return 429. Unreported output remains an empty log; ledger pointers and runner files are never opened.
- **Tests:** `tests/test_coworker_livelog_contract.py` pins the HTTP contract; `tests/test_coworker_livelog.py` covers both routes, the redaction and isolation matrix, source binding, bounds, cursor semantics and step-state mapping.
