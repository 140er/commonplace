- **Owns:** The workspace's default model per role (card #661): `models.put_workspace`, `workspace_roles`, `options`, `suggestions` and `SUGGESTED` (Grok 4.7), and `GET|PUT|POST /api/settings/models` with `model_suggestions` on the project view. In `model_modes`: one active connection per machine and provider, all of one person (index `model_connections_machine_provider`, replacing `model_connections_machine`), `linked_providers`, `linked` per role in `effective_for`, and the sign-in items (`note_signed_out`, `clear_signed_out`, `signin_needs`, `cli_problem_words`).
- **Promises:** Any signed-in person reads the workspace's choices; only a signed-in owner writes them, others get 404, and each write is audited (`models.workspace`). A project's own choice wins per role. A suggestion is offered in every picker but is never on a list until chosen and never a default, so a project with no choice keeps today's behaviour. Every role read-back carries provider, model, source, mode, account kind, the caller's own label and `linked`; never a credential and never another person's label. The index change is applied in place on every open and keeps every row.
- **How it fails:** A model that is neither listed nor suggested is refused with `unknown_model` and nothing is written. An unreadable mode store leaves the read-back without account fields (settings) or fails closed (starts and chat, as in slice 1).
- **Tests:** `tests/test_model_roles_own_subscription.py`, `tests/test_projects_models.py`, `tests/test_model_modes.py`.
