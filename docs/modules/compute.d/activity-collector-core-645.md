- **Owns:** `activity_collector.py`, `activity_math.py` and `activity_schema.py`: the read-only, bounded local Activity collector and its strict aggregate contract.
- **Promises:** The core imports only its sibling modules and the standard library. Source SQLite opens with `mode=ro` and `query_only`; raw source text, titles, paths, command arguments and errors cannot enter aggregate labels. Collection discovers no credentials and performs no implicit network operation. An explicit caller-supplied report callback remains responsible for authorization.
- **Promises:** Untimed preparing, starting, running and waiting requests made before the window ends survive both SQL eligibility and Python retention, including requests made before the window starts. Their status and active count remain visible; `runs_untimed` records missing coverage and an entirely untimed observation reports `agent_hours` as unavailable with `no_timing`. Request time is never execution start time.
- **How it fails:** Invalid timestamps remain untimed; future requests and historical completed requests do not become active work. Existing global scan limits and overflow reporting still apply. Missing or malformed sources raise only `activity_source_unavailable`.
- **Tests:** `tests/test_compute_activity_collector_core.py`, `tests/test_compute_activity_collector_core_regressions.py` and `tests/test_compute_activity_untimed_active.py` use `tests/activity_core_fixtures.py` and real disposable SQLite databases.
