- **Promises:**

  - The release journey drives the app by its current visible names (project, Project name, Create project, Search memory, Workspace) and releases an agent-created card as the signed-in owner before the agent claims it. Returning logins are only required to reach the signed-in shell; new signups must land on the board.

  - The first memory write of a fresh workspace gets a longer deadline than other calls because it starts the memory worker. Failures inside SDK task groups are reported by their leaf errors, and a refused MCP call includes the server's first 300 characters of reason.

- **How it fails:**

  - A rename in the app that the journey does not follow fails the browser-free interface-name test instead of surfacing as a timeout in a nightly run.
