- **Owns:**

  - `tools/bots_learning_relevance.py` is the optional S6 informational check for learning memory. Run `uv run python tools/bots_learning_relevance.py --seed 464 --conversations 36` on a quiet machine. It creates temporary synthetic conversations, uses a fixed-output stub model to select verbatim items, and compares the existing retrieval and prompt builder with learning off and on. The first line is the percentage-point gain in conversations whose expected learned item reaches the prompt; the small table reports each hit rate and mean added input characters (including labels, JSON and the learned-item rule). The balanced cases cover lexical corrections, standing preferences, standing instructions and a paraphrase with no lexical overlap, alongside shuffled distractors. The teaching messages are outside the simulated history window. This checks retrieval, not extraction or generated-answer quality; synthetic coverage is not evidence of general conversational accuracy. The seed controls teaching order; the clock is fixed and random identifiers have fixed lengths, so output is repeatable. All data is temporary; no network, provider, workspace configuration or live conversation is used. It exits normally regardless of the score and is not part of merge selection.
- **Tests:**

  - `tests/test_bots_learning_relevance_output.py` runs four synthetic conversations twice with seed 7 and checks only the report shape and repeatability, with no relevance or size threshold.
